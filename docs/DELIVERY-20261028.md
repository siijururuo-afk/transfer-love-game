## 实际代码修改

- 节目入口：白底黑色韩文标题、五色 SVG 线路及站点。只用于 TVING，未用于手机壁纸；没有裁切概念图。
- X介绍信：真实正文仍是可滚动、可调整字号的文本，信纸样式与任务纸张分开，无新增人物资料。
- Talking Room：第四章的变声语音段落采用隔断意象与逐人文字转录；第二、第五章仍为键盘聊天。没有伪造音频。
- X Room：木色、纸面与引语层级，只使用已有正文，不增加假照片和信物。
- 采访：明确为文字转录，保留问答正文；没有假采访画面。
- 任务纸张、X公开结果、短信和预告字幕分别呈现。X公开结果采用既有原文日期与人物。
- 通知中心只保留17个实际接收短信事件拆出的23条消息。历史论坛、正片、照片不再生成系统通知或响提示音；阅读推进仍有独立的即时阅读提示。
- Instagram删除上一篇／下一篇、编辑资料入口；Story打开即读、关闭退出；多图位置、点赞、收藏继续持久保存；全屏增加双击／按钮缩放、拖动与双指处理，避免触发手机返回手势。
- 论坛恢复有证据的theqoo与Instiz来源。未知来源保留中性界面，不假装是Daum Café。
- 修复320px封面容器被宽高比撑宽的问题。既有iOS17外壳、壁纸、Melon、照片、电话、日历、时钟、Safari、设置、存档与PWA保留。
- GitHub Pages流程增加剧情、交互、存档和PWA检查；替换依赖旧工作区目录的审计脚本。

## 尚未完成／验证限制

1. **356条逐段韩中语义审校未完成。** 这属于尚未完成的工作，不是没有原文，也不是客观无法处理；不能把本轮局部修订包装成全篇审校。
2. 所有App与2023年底韩国iPhone历史版本的逐项视觉考据、全部交互重做尚未完成。本轮主要修复上述具体页面；没有声称每个App都已精确还原。
3. 本环境没有实体iPhone／iOS Safari，因此尚无真机Safari、WebKit音频后台、双指触控、PWA安装及离线阅读的最终实测结论。浏览器检查使用Chromium移动模拟。
4. 外部歌曲试听与YouTube的地区限制、长期有效性和全部播放行为未穷尽验证；保持现有源，没有制作假视频或替换歌曲。
5. 原始图片URL在附件中缺失，不能反查全部原图身份或补造照片；X Room因此以原文和已有素材为界。
6. 本轮没有制作AI配音。
