# 本轮内容审校与现有页面精修

本文记录本轮代码及本地验收。发布提交和线上版本以 GitHub Actions、version.json 及最终交付链接为准，不沿用上一轮上传前的拦截状态。

## 内容

十二部分、356条记录全部排查。355条可获取文字已完成韩中语义对照，建立1,958组明确分组的段落对应。不是逐字数对齐：源文中连续评论、通知或同一段内的换行，按原文实际结构分组。源行号是article提取行，非HTML物理行。

唯一无法核实的文字记录为 `e1-question-story`：外传上L22只有未保存的图片占位，无贴纸文字。保留现有记录，显式标记不可核实，不编写韩文补足。图片、视频身份和缺失原图仍不等于已核实。

这轮新增31项有原文依据的修订，累计日志61项。包括待机室/候机室、认识/交往、拍摄强度、四人分组、称呼、상남자、十九年/从19年开始等问题；第五章被概括的大段引述已恢复，第七章漏掉的同时性叙述已补回采访之后、短信之前，没有塞进短信气泡。准确内容保留。

111条论坛来源重新核对标题、身份标记及可获取链接，并记录源哈希、行段、原始评论缩进。20条theqoo、1条Instiz、90条仍无可靠平台证据。所有记录的可见评论标记数量及嵌套与给定原文一致；不能因为未知来源就假造Daum界面或楼层。

## 页面和交互

- 字体与字号保持原设置。原programme.css完整前缀保留，phone.css未改。
- 356条显式写入presentation类型；修改中文标题不再改变场景分类。
- 42条采访统一问题、说话人、回答和叙述层级，停顿、心理描写、插入叙述不删。第四章变声Talking Room与文字聊天室分开，X Room引语用纸面层级呈现，不新增假照片、道具或音频。
- 手机系统App名称、日期、消息、文件、电话、照片、日历、时钟、设置及主要导航改为韩文，剧情保持中文。旧照片/Safari标签状态可兼容。
- 设置→읽기 도구→韩中原文对照，默认关闭，随存档持久保存。只显示已经核对的对应；不可核实的贴纸显示原因。对照模块延后加载。
- 锁屏继续查看入口改为独立小入口，普通历史内容不冒充系统通知；23条真实短信通知规则保持不变。
- 音乐播放失败提供重试，区分中断与错误，安全恢复进度，兼容不支持部分MediaSession操作的浏览器；不强制恢复播放。Instagram视频保存位置、去重错误提示并提供重试。
- 设置增加版本检查；生产页面写入构建版本，配合既有PWA网络优先更新和旧缓存清理，发现新版后由用户选择重新打开。构建脚本重复运行版本一致。

## 验收

通过：生产构建、12章译文导出、356个ID与原顺序、交互/通知、13个旧存档检查点、导入错误回滚、72个旧媒体文件不变、PWA、固定呈现类型、355条对照重组、1条不可核实例外及原字体保持检查。

Chromium153手机模拟逐一打开356条记录，未发现页面异常、缺失图片或页面横向滚动。七个节目样例在320/360/375/390/430px通过。浏览器另验证对照默认关闭和持久保存、第四章对照、贴纸不编造原文、锁屏入口独立及浏览器阻止播放后重试。

## 仍需真实设备确认

本环境无实体iPhone，不能完成真实iPhone Safari手势、系统后台音频、主屏幕安装和跨系统中断恢复的最终验收。Chromium结果不替代真机。第三方音源和YouTube的地区或嵌入限制仍依赖外部服务。

真机可从设置点击“업데이트 확인”，确认版本后测试双指缩放、系统返回手势、锁屏后台音乐及添加到主屏幕后的离线重开。不能凭服务器构建成功断言这些项目已通过。
